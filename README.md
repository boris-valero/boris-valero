## 💼 Projects

### 🔷 FramaSpace Hexagonal
> ⏱️ *mai 2025 – mai 2026*

**Description | 🇫🇷**

Application **Nextcloud** qui agrège les **métriques d'usage** des services Framasoft et personnalise leur affichage. Développement en **architecture hexagonale (Clean Architecture)** qui transforme une application monolithique en un système **modulaire, testable et évolutif**.

| Caractéristique | Description |
|----------------|-------------|
| 🏗️ **Cœur métier isolé** | Logique pure, sans dépendance aux frameworks ou bases de données |
| 🔌 **Adaptateurs interchangeables** | SQL, cache (Redis/APCu), API externes… tout est adaptable |
| 🎯 **Contrôleurs ultra-légers** | Plus de mélange de responsabilités, juste de la coordination |

**Stack technique :** `Laravel` `PHP` `Nextcloud` `Redis` `APCu` `MySQL`

**Description | 🇬🇧**

**Nextcloud** application that aggregates **usage metrics** from Framasoft services and personalizes their display. Developed with **hexagonal architecture (Clean Architecture)** transforming a monolithic app into a **modular, testable, and scalable system**.

| Feature | Description |
|---------|-------------|
| 🏗️ **Isolated core domain** | Pure logic, no framework or database dependencies |
| 🔌 **Swappable adapters** | SQL, cache (Redis/APCu), external APIs… everything is adaptable |
| 🎯 **Lightweight controllers** | No mixing of responsibilities, just orchestration |

**Tech stack:** `Laravel` `PHP` `Nextcloud` `Redis` `APCu` `MySQL`

### ☁️ Nextcloud — Migration AWS S3 Storage + Docker
> ⏱️ *Projet professionnel | Framasoft*

**Description | 🇫🇷**

Conception et mise en œuvre de la **migration du stockage Nextcloud** vers **AWS S3**, avec une infrastructure entièrement conteneurisée.

| Étape | Détail |
|-------|--------|
| 🏗️ **Architecture** | Migration de stockage monolithique vers infrastructure cloud-native |
| 🐳 **Conteneurisation** | Stack complète avec **Docker** (Nextcloud + Redis + MariaDB) |
| ☁️ **Stockage objet** | Configuration **AWS S3** comme stockage principal |
| 🔄 **CI/CD** | Automatisation avec **GitHub Actions** (build, test, déploiement) |
| 📦 **Déploiement** | Infrastructure-as-Code via **Ansible** |

**Stack technique :** `Docker` `AWS S3` `Nextcloud` `MariaDB` `Redis` `Ansible` `GitHub Actions` `CI/CD`

**Description | 🇬🇧**

Designed and implemented the **migration of Nextcloud storage** to **AWS S3**, with a fully containerized infrastructure.

| Step | Detail |
|------|--------|
| 🏗️ **Architecture** | Migrated from monolithic storage to cloud-native infrastructure |
| 🐳 **Containerization** | Full stack with **Docker** (Nextcloud + Redis + MariaDB) |
| ☁️ **Object storage** | Configured **AWS S3** as primary storage backend |
| 🔄 **CI/CD** | Automated with **GitHub Actions** (build, test, deploy) |
| 📦 **Deployment** | Infrastructure-as-Code via **Ansible** |

**Tech stack:** `Docker` `AWS S3` `Nextcloud` `MariaDB` `Redis` `Ansible` `GitHub Actions` `CI/CD`
